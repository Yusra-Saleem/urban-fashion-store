# Urban Fashion Boutique

> Modern urban lifestyle fashion, accessories, and boutique web platform.

## Overview

A chic fashion e-commerce storefront presenting curated boutique apparel, accessories, and modern wardrobe essentials with clean filtering and checkout UI.

## Key Features

- Curated collection sections: Trending, New Arrivals, and Essentials
- Interactive product modal with specifications, materials, and sizing
- Persistent cart drawer state with instant order subtotal calculation
- Minimalist responsive aesthetic crafted with Tailwind CSS

## Architecture and Technology Stack

- **Core Technologies:** Next.js, React, TypeScript, Tailwind CSS, Shadcn UI
- **Author:** Yusra Saleem
- **Portfolio:** [yusrasaleem.dev](https://yusrasaleem.dev)

## Getting Started

### Prerequisites

Ensure you have the required runtime environment installed for this repository:
- Node.js (v18+) for JavaScript/TypeScript projects
- Python (3.10+) for Python services and agent workflows

### Installation

Clone the repository to your local machine:

```bash
git clone https://github.com/Yusra-Saleem/urban-fashion-store.git
cd urban-fashion-store
```

Install dependencies:

```bash
# For Node / Next.js projects
npm install

# For Python projects
pip install -r requirements.txt
```

### Running Locally

```bash
# Start local development server
npm run dev

# Or for Python entry points
python main.py
```
